# Direct User Research Method — Unknown Values / Shapes via Variant-Relation Search — 2026-09-04

Status: USER-DIRECT OPERATING GUIDANCE

## User directive

When an important value, threshold, geometry, or pattern characteristic is still unknown, do not leave it unresolved by default. Use the same bounded research method already adopted in the project:

```text
UNKNOWN
-> define candidate variant 1 / 2 / 3 (or another small bounded set)
-> measure each variant reproducibly
-> compare source-consistency where labeled/source examples exist
-> compare historical outcome relationships separately
-> eliminate inconsistent / unhelpful variants
-> narrow the search space
-> repeat only when the next test can materially reduce uncertainty
```

## Evidence separation

Two questions must remain separate:

1. `SOURCE-RULE IDENTIFICATION` — Which candidate best matches the instructor/source-labeled examples?
2. `OUTCOME USEFULNESS` — Which candidate, if any, changes forward outcome behavior in historical data?

Historical performance alone must not be used to declare what the instructor meant.

## Closure discipline

Each bounded variant comparison must close as one of:

- `SUPPORTED`
- `NOT_SUPPORTED`
- `INCONCLUSIVE`
- `INDISTINGUISHABLE`
- `NOT_TESTABLE_WITH_CURRENT_EVIDENCE`

Unknowns should not remain indefinitely open when variants can be tested. If multiple variants cannot be separated by available evidence, close them as `INDISTINGUISHABLE` rather than forcing a formula.

## Current priority unknowns suitable for this method

### 1. SW / Sideway measurable representation

Do not invent a canonical SW rule. Build a small set of explicit proxy families from measurable price-state features and compare them against any source-labeled SW cases plus forward outcomes. Candidate families should be kept small and frozen before evaluation.

### 2. Inherited remaining-run reconstruction

Compare bounded origin-SIG/run reconstruction variants using only information known before 07:00. Candidate anchors must remain explicitly labeled research variants until source evidence selects among them.

### 3. PAT3 unresolved geometry

Small-body / wick-balance / 50% measurement basis should be represented as bounded candidate variants rather than one guessed threshold. Source-consistency and outcome usefulness are evaluated separately.

### 4. Por Chon body-sensitive standing geometry

Test bounded interpretations such as close-only / whole-body-side / body-intersection variants against source-labeled visual cases before using outcome data to evaluate usefulness. Do not let better backtest performance choose the canonical teaching rule.

### 5. MTF alignment strength

The user-direct rule is already graded: more aligned H1/M30/M15/M5 timeframes is stronger. Measure 0/1/2/3/4 aligned counts and outcome relationships. Do not invent a production minimum from backtest performance alone.

## Operating principle

```text
If we do not know a value or shape but it is measurable:
DO NOT GUESS ONE VALUE.
SEARCH A SMALL BOUNDED SET OF VARIANTS AND STUDY THE RELATIONSHIP.
```

This method extends the existing hypothesis-first research policy and does not weaken provenance rules.
