# RQ-009 — Body Collection vs Partial S/R Component Reconciliation

Date: 2026-09-09 Asia/Bangkok
Sources: EP.4 `UV5NijhjfJ8`, EP.5 `oCcG3dUjrgw`, EP.6 `16KoS7d-koI`
Status: `SOURCE_BACKED_PARTIAL_COMPONENT_SR_EXISTS / ARBITRARY_BODY_COLLECTION_MERGE_UNRESOLVED`

## Why this reconciliation is needed

The latest EP.5 checkpoint closed one specific Body Collection cross-timeframe topology:

```text
parent/reference TF: ซอก + ไส้ -> two forecast/reference levels
lower TF: คู่ -> ตรงกัน / aligned with an existing parent reference
-> complete ซอก + ไส้ + คู่ structure
-> no third forecast line
```

A follow-up scan of EP.4 and EP.6 found direct teaching that **partial ซอก/ไส้/คู่ combinations can also exist as weaker support/resistance structures**, especially on lower timeframes.

Therefore the project must not conflate:

1. a full/strong `ซอก + ไส้ + คู่` zone used in the higher-timeframe/reference context; and
2. a lower-timeframe minor S/R reference that may contain only one or two of those components.

This document reconciles those two source-backed ideas without inventing a universal cross-timeframe merge rule.

---

## 1. EP.4: complete three-component structure is the strong/full zone

### ~12:08–12:24

The instructor states that `ซอกไส้คู่` must occur with all three components for the structure to be strong and to be called the zone in the taught higher-level sense. The wording says one component cannot simply be omitted from that complete set.

Safe source statement:

```text
complete strong/full zone => ซอก + ไส้ + คู่
```

This is consistent with EP.5 Body Collection teaching that the complete structural set is required.

---

## 2. EP.4: lower-timeframe minor S/R may use partial components

### ~1:17:45–1:18:09

The instructor then explicitly distinguishes lower-timeframe usage:

- a lower timeframe may use only a `คู่` as a small support;
- `ไส้ + คู่` can also be used;
- it does not have to be as complete there;
- but the large/higher timeframe should have the full `ซอก + ไส้ + คู่` set.

Safe source distinction:

```text
higher/reference TF strong/full zone:
    ซอก + ไส้ + คู่ complete

lower TF minor S/R:
    partial component structure may be usable
    e.g. คู่ only or ไส้ + คู่
```

This does **not** say that any partial lower-timeframe structure may automatically be merged into a Body Collection forecast candidate.

---

## 3. EP.6 independently names partial component combinations as weaker

### ~1:11:49–1:12:36

The instructor reviews a full `ซอก + คู่ + ไส้` zone and then directly explains that if all three are not present, the structure is less strong. Explicit partial examples include:

- `ไส้ + คู่`;
- `คู่ + ซอก`;
- other two-component combinations.

The source comparison is qualitative strength, not a deterministic entry rule:

```text
3 components complete -> stronger
2 components -> weaker
```

No numeric strength score or universal ranking distance is taught here.

---

## 4. EP.6: components can occupy the same zone/range without exact-price identity

### ~1:14:08–1:14:27

The instructor points to a `คู่`, a `ซอก`, and multiple wicks and says they are `อยู่ในระยะเดียวกัน`, then treats the area as the next support.

This supports a **zone/range relationship**, not proof that every component price must be exactly equal tick-for-tick.

Safe semantic:

```text
component references may belong to the same structural area/zone
```

Still unresolved:

```text
exact broker-tick equality
allowed point distance
overlap threshold
spread-aware normalization
```

No numeric tolerance may be invented from outcomes.

## 5. EP.6: nearby alternatives and nearest-first guidance exist in S/R selection context

### ~1:14:38–1:15:32

The instructor says nearby alternative pair choices are not necessarily wrong because the distances are close. Shortly after, when selecting among support/reference areas, the instructor says `เลือกที่ใกล้ที่สุดก่อน` (choose the nearest first).

The same sequence includes a learner asking whether overlapping Day + H4 references are stronger; the instructor answers that they are stronger and says multi-timeframe overlap will be taught separately.

Safe source-backed S/R guidance:

```text
when selecting among nearby S/R reference areas in this reviewed context:
    nearest first

multi-timeframe overlap:
    qualitatively stronger
```

Critical guard:

This is **support/resistance-zone selection guidance**. It is not sufficient evidence to promote `nearest-first` into a universal Body Collection same-timeframe candidate winner rule.

The Body Collection candidate-priority blocker therefore remains open unless a Body Collection-specific source states the same rule.

## 8. Reconciliation with the latest EP.5 cross-TF alignment checkpoint

The following facts can coexist without contradiction:

### A. Full/strong structure

```text
complete higher/reference zone:
    ซอก + ไส้ + คู่
```

### B. Partial minor S/R

```text
lower-TF/minor S/R may exist with:
    คู่ only
    ไส้ + คู่
    คู่ + ซอก
    or other incomplete combinations

but source describes these as weaker than complete 3-component structure
```

### C. One explicit Body Collection cross-TF completion topology

```text
parent/reference TF:
    ซอก + ไส้ -> two forecast/reference levels
lower TF:
    คู่ aligns with an existing parent reference
-> completes full Body Collection structural set
```

### D. What is NOT established

The current source set still does not establish a universal algorithm such as:

```text
any arbitrary parent partial subset
+
any lower-TF partial subset
-> automatically merge
-> choose two references by fixed arithmetic/ranking rule
```

That would be an analyst-created rule and is prohibited.

## 9. Decision

### Source-backed now

1. Complete `ซอก + ไส้ + คู่` is the stronger/full zone structure in the reviewed higher/reference-timeframe teaching.
2. Partial one- or two-component structures can exist as weaker lower-timeframe/minor S/R references.
3. Explicit partial examples include `คู่` alone, `ไส้ + คู่`, and `คู่ + ซอก`.
4. Components can belong to the same zone/range without source proof of exact tick equality.
5. In the reviewed S/R-selection context, nearest candidate area is chosen first and overlapping higher-timeframe references are qualitatively stronger.
6. These S/R rules do not automatically become Body Collection candidate-priority or arbitrary cross-TF merge rules.

### Still unresolved

- universal Body Collection cross-TF merge for arbitrary component permutations;
- exact machine geometry/tolerance for `อยู่ในระยะเดียวกัน` / `ตรงกัน`;
- Body Collection-specific same-TF winner when several valid candidates coexist;
- priority when several lower-TF components could complete one parent partial candidate;
- universal mapping of multiple valid component prices into exactly two forecast references outside the already closed shown topology;
- exact quantitative strength advantage of full vs partial structures;
- exact multi-timeframe overlap geometry.

## Final classification
