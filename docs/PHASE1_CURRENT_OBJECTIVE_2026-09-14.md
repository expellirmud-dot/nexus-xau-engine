## Missing-value / equation-gap doctrine

Classify unresolved values before allowing them to block or bypass research:

- DERIVABLE
- NON_BLOCKING_UNKNOWN
- BLOCKING_UNKNOWN
- IRRELEVANT_TO_CURRENT_DECISION
- IRREDUCIBLE_OR_NOT_YET_REDUCIBLE

Do not classify a value as DERIVABLE merely because confidence feels high. Test whether materially different values can remain consistent with current evidence and whether those alternatives change the downstream conclusion.

## Contradiction doctrine

If two evidence-backed relationships conflict, do not automatically pick a winner. Test conditioning state, missing interactions, regime differences, supersession/history, and whether the representation is too coarse.

A real contradiction is a research input, not an automatic blocker of the whole Project.
