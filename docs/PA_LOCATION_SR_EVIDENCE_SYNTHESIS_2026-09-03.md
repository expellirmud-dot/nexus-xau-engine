# PA Location / Support-Resistance Evidence Synthesis — 2026-09-03

Status: ACTIVE RESEARCH / EVIDENCE CONSOLIDATION

Purpose: consolidate all currently available project evidence relevant to the hard PA location rule so the engine does not collapse multiple frame/zone families into one invented generic S/R formula.

## Executive conclusion

The hard semantic rule is closed:

```text
BUY PA/PAT  = valid only at SUPPORT
SELL PA/PAT = valid only at RESISTANCE
```

However, the project evidence shows that `support/resistance` is not represented by one universal construction. Multiple source families are used in different setup contexts. Therefore the engine must preserve the source family of every location qualification.

A boolean such as `at_support=True` without a traceable source family is insufficient for reproducible research.

## Evidence-backed location families

### 1. Mae Pla daily statistical frame

Primary-image evidence supports a practical first-pass construction:

```text
07:00 H4 context
-> nearby statistical price ending in 0 or 5
-> minor S/R reference
-> upper = reference + 500 points
-> lower = reference - 500 points
```

The outer spacing is therefore 1,000 points.

Still unresolved:

- exact timezone normalization for the 07:00 reference;
- exact nearest-price / rounding / tie rule for 0/5 selection.

Status: construction materially supported, final snap/time rule still PARAMETERIZED.

### 2. H4/H1 wick-contact frame

Primary teaching material states:

- H4 wick-end contacts are used to identify strong frame references;
- H4 wick tips touching within approximately 7–14 points are described as strong-frame contact;
- H1 wick tips can be used for minor S/R with a similar 7–14-point contact concept.

Important interpretation:

`7–14 points` is evidence for *contact/confluence strength between wick references in the demonstrated frame-building method*.

It is NOT evidence for:

- a universal PAT-to-frame distance tolerance;
- a universal entry distance;
- a universal S/R penetration allowance.

Status: source-family rule supported; do not reuse 7–14 outside its evidenced role without a named experiment.

### 3. Body-collection zone (`ซอก + ไส้ + คู่`)

Primary transcript evidence supports historical candle structures as S/R context:

- `ซอก`: candle price junction / close-open reference;
- `ไส้`: wick reference;
- `คู่`: alternating-color pair/equilibrium area;
- all three together form the demonstrated body-collection zone;
- same-timeframe search is preferred, with H4 -> H1 -> M30 fallback examples;
- zone 1 / zone 2 are projections, not necessarily one exact price;
- a near miss of about 100 points occurs in one accepted example, but is example-specific.

Still unresolved:

- exact OHLC formula for `ซอก`;
- exact `คู่` geometry;
- exact tolerance and zone boundaries;
- exact touched/collected/retired transitions.

Status: concept/workflow CONFIRMED; exact detector NOT IMPLEMENTED / HUMAN CONFIRM.

### 4. Por Chon ATH frame

Primary image evidence supports:

- require roughly 1,000-point run from previous ATH frame condition;
- use highest H4 price in the stated 19:00–19:00 interval for the new ATH candidate;
- no new frame if required conditions are absent;
- created frame persists as an important S/R/navigation reference;
- compare with Mae Pla frame for proximity/confluence.

Still unresolved:

- exact timezone/day-boundary meaning of 19:00–19:00;
- tie handling and replacement/retirement details.

Status: PARAMETERIZED / HUMAN CONFIRM.

### 5. Sideway frame

Project evidence supports Sideway as its own setup/location family. It is not equivalent to the ordinary daily frame or body-collection zone.

Still unresolved:

- exact upper/lower frame construction;
- frame-complete event;
- breakout/false-break geometry;
- exact transition to new SIG.

Status: state shell CONFIRMED; canonical location detector NOT IMPLEMENTED.

### 6. Manual / visually identified S/R

Primary PA slide and transcript directly show BUY patterns standing on support and SELL patterns standing on resistance. The instructor also states that larger-timeframe S/R context can override a smaller-timeframe shape.

But when the actual support/resistance line is manually identified from a chart rather than generated by one of the source-family algorithms above, it must be recorded as `MANUAL_SUPPORT_RESISTANCE` with evidence/annotation. It must not silently become a deterministic auto-detected frame.

## Tolerance findings

Several point distances appear in the project, but they belong to different contexts.

### `7–14 points`

Evidence role: H4/H1 wick-contact strength when constructing strong/minor frame references.

Do NOT reinterpret as universal PA location tolerance.

### `<= ~200 points`

Evidence role: entry/frame proximity in a specific teaching slide; price may also pierce S/R by about this amount in the demonstrated cycle/entry context.

Do NOT reinterpret as universal PA location tolerance or body-collection zone tolerance.

### `~100 points`

Evidence role: one body-collection example where price fell short of a projected level and was still discussed as usable.

Example only, not a universal body-zone tolerance.

### `~200 points` post-SIG destruction example

Evidence role: one illustrated invalidation/destruction case.

Not a universal SIG-destruction threshold.

## Conflict correction

An older `RULEBOOK.md` sentence states that PA Sell may occur at resistance **or** at a frame/area where TP run is complete. Stronger later direct user evidence and the primary PAT transcript make the rule stricter:

```text
BUY PA/PAT valid only at support
SELL PA/PAT valid only at resistance
```

A completed run can be context for looking for reversal evidence, but it is not itself a substitute for the required support/resistance location.

Engineering precedence: the later direct rule supersedes the older weaker wording while the old record remains preserved for history.

## Engineering decision — 2026-09-03

Added `src/nexus_xau/engine/location.py` with explicit source families:

```text
MAE_PLA_STAT_FRAME
WICK_CONTACT_FRAME
BODY_COLLECTION_ZONE
POR_CHON_ATH_FRAME
SIDEWAY_FRAME
MANUAL_SUPPORT_RESISTANCE
UNKNOWN
```

The new `LocationContext` stores:

```text
source_type
side
source timeframe
frame/zone id
price or zone bounds
distance_points
qualifies = true | false | unknown
evidence_note
```

Location evaluation intentionally fails closed when:

- no context is supplied;
- BUY is paired with resistance or SELL with support;
- source family is unknown;
- source-family-specific qualification is unresolved.

A location can pass only when the correct side and traceable source family are supplied and the family-specific qualification has been externally/deterministically established.

This prevents a generic `at_support=True` flag from hiding unresolved S/R construction.
