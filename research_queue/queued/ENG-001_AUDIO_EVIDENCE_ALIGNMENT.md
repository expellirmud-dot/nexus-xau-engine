# ENG-001 — Audio evidence extraction and timestamp alignment

Status: ON_DEMAND
Type: INFRASTRUCTURE

## Activate only when

An active research worksheet reaches a material ASR ambiguity that transcript + visual frames cannot resolve safely.

## Purpose

Extract the relevant original audio segment from local MP4, align it with the same timestamp window used for visual evidence, and preserve:

- original audio segment;
- YouTube ASR text;
- normalized/verified transcript;
- source timestamp;
- visual evidence references.

## Guard

Do not build or run this merely because audio would be nice to have. Activate it when ambiguity can change a rule, number, timeframe, or technical term.
