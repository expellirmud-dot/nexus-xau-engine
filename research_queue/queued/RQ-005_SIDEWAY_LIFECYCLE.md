# RQ-005 — Sideway construction, completion, and transition to new SIG

Status: QUEUED

## Why this matters

Sideway is used as a market-state concept, but exact boundaries and completion/transition semantics are not yet frozen. Wrong sideway state can contaminate setup eligibility, frame interpretation, and new-SIG lifecycle logic.

## Primary method when activated

Use source-first visual review to identify how sideway begins, persists, ends, and hands off to a new SIG. Only after those visual/source semantics are explicit should OHLC state features be measured.

## Done when

A replayable state transition is established, conditionally parameterized, or closed inconclusive with exact missing evidence named.
